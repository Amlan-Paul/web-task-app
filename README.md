# WebTask Manager — Role-Based Website Update & Task Management System

Google Sheet-ভিত্তিক রোল-বেজড (RBAC) ওয়েবসাইট টাস্ক, ডিপ্লয়মেন্ট আপডেট, অডিট লগ এবং ইউজার ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন।

## প্রধান ফিচারসমূহ:
1. **রোল-বেজড লগইন ও লগআউট সিস্টেম (RBAC Authentication)**:
   - ইমেইল ও পাসওয়ার্ড দিয়ে নিরাপদ লগইন এবং সেশন সংরক্ষণ (`Users_Database` সিটের সাথে সমন্বিত)।
   - ৪টি নির্দিষ্ট রোল ও অ্যাক্সেস কন্ট্রোল:
     - **Admin (`sadia@webtask.io` / `admin123`)**: সম্পূর্ণ সিস্টেম কন্ট্রোল (টাস্ক ও আপডেট তৈরি, এডিট, ডিলিট, ইউজার ম্যানেজমেন্ট, অডিট লগ এবং শিট কনফিগারেশন)।
     - **Developer (`tanvir@webtask.io` / `dev123`, `rafiq@webtask.io` / `dev123`)**: টাস্ক তৈরি ও এডিট, স্ট্যাটাস পরিবর্তন, নতুন রিলিজ আপডেট প্রকাশ, অ্যানালিটিক্স ও অডিট লগ ভিউ।
     - **QA (`nusrat@webtask.io` / `qa123`)**: টাস্ক রিভিউ, স্ট্যাটাস পরিবর্তন (In Progress / Review / Completed), বাগ রিপোর্ট/নোট আপডেট এবং অডিট লগ ও অ্যানালিটিক্স ভিউ।
     - **Viewer (`viewer@webtask.io` / `view123`)**: শুধুমাত্র রিড-অনলি ভিউ (কানবান বোর্ড, টাস্ক তালিকা ও CSV এক্সপোর্ট, আপডেট লগ এবং অ্যানালিটিক্স)।
2. **কানবান বোর্ড ও টাস্ক ডাটাবেস (`Tasks_Database`)**:
   - ড্র্যাগ-অ্যান্ড-ড্রপ ও কুইক স্ট্যাটাস পরিবর্তন, "আমার টাস্ক (My Tasks)" ফিল্টার, সার্চ এবং CSV এক্সপোর্ট।
3. **ওয়েবসাইট আপডেট ও রিলিজ চেঞ্জলগ (`Website_Updates_Log`)**:
   - লাইভ, স্ট্যাজিং এবং রোলব্যাক রিলিজ ট্র্যাকিং ও টাইমলাইন।
4. **অডিট লগ ও সিকিউরিটি ট্র্যাকার (`Audit_Logs`)**:
   - প্রতিটি লগইন, টাস্ক তৈরি/আপডেট/ডিলিট, স্ট্যাটাস পরিবর্তন এবং ডিপ্লয়মেন্টের স্বয়ংক্রিয় অডিট লগ রেকর্ড ও ফিল্টারিং।
5. **টিম ও ইউজার ম্যানেজমেন্ট (`Users_Database`)**:
   - অ্যাডমিন প্যানেল থেকে নতুন ইউজার যুক্ত করা, রোল পরিবর্তন, অ্যাকাউন্ট Active/Inactive করা এবং পাসওয়ার্ড ম্যানেজমেন্ট।

## ফাইল তালিকা:
- `index.html`: সম্পূর্ণ ফ্রন্টএন্ড ওয়েব অ্যাপ (HTML, Tailwind CSS, JavaScript, Chart.js)।
- `Code.gs`: Google Apps Script কোড যা ৪টি শিটকে (`Tasks_Database`, `Website_Updates_Log`, `Audit_Logs`, `Users_Database`) দ্বিমুখী REST API ডাটাবেসে পরিণত করে।
- `CNAME`: কাস্টম ডোমেইন কনফিগারেশন (`tracker.holycare.my.id`)।

## গুগল শিট সেটআপ নির্দেশিকা:
1. আপনার Google Sheet ওপেন করুন: `Extensions` > `Apps Script` মেনুতে যান।
2. `Code.gs` ফাইলের কোড পেস্ট করুন এবং Save করুন।
3. ডানদিকের `Deploy` > `New deployment` চাপুন।
4. `Select type` হিসেবে `Web app` সিলেক্ট করে Access দিন `Anyone` এবং Deploy করুন।
5. প্রাপ্ত Web App URL টি অ্যাপ্লিকেশনের **"শিট কনফিগ"** ট্যাবে যুক্ত করুন (Admin হিসেবে লগইন অবস্থায়)।
